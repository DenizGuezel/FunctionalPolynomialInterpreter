# Manueller Testplan

Diese Liste ist für einen kurzen manuellen Durchgang durch die GUI gedacht.

## Eingabe und Polynomliste

- Anwendung starten.
- z.B. Polynom 3 2; 2 1; 1 0 hinzufügen.
- Prüfen, ob es in der Polynomliste erscheint.
- Noch ein Polynom hinzufügen, z.B. 1 1; -4 0.
- Ein Polynom auswählen und Auswahl löschen testen.
- Ein Polynom auswählen und Polynom entfernen testen.

## Operationen

- Ein Polynom auswählen und Normalisieren testen.
- Ein Polynom auswählen und Negieren testen.
- Ein Polynom auswählen und Ableiten testen.
- Ein Polynom auswählen, einen x-Wert eingeben und Auswertung testen.
- Mindestens Zwei Polynome auwählen, einen x-Wert eingeben und parallele Auswertung testen.
- Zwei Polynome auswählen und Addieren testen.
- Zwei Polynome auswählen und Subtrahieren testen.
- Zwei Polynome auswählen und Multiplizieren testen.
- Zwei Polynome auswählen und Dividieren testen.

## Fehlerfälle

- Ohne Auswahl eine Operation starten.
- Bei Addieren nur ein Polynom auswählen.
- Division durch das Nullpolynom testen.
- Ungültige Eingabe testen, z.B. abc 2.
- Negativen Exponenten testen, z.B. 3 -1.
- Auswerten ohne x-Wert testen.

## Darstellungen

- Ergebnis anzeigen.
- LaTeX anzeigen.
- Baum anzeigen.
- Analyse anzeigen.
- Schritte anzeigen.
- Details anzeigen.
- Graph anzeigen.
- Historie anzeigen.

## Weitere Funktionen

- Zufallspolynom erzeugen.
- Beispiele laden.
- Parallel mit einem x-Wert testen.
- Eine Operation zweimal ausführen und prüfen, ob beim zweiten   Mal der Cache benutzt wird.
